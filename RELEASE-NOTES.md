# Crash Scout release notes

## 1.1.1 - November 13, 2026
- Release notes are now inside the program (Help tab, Release Notes button).
- New Help buttons: Watch the Video (the narrated explainer on dialsoft.com) and dialsoft.com.

## 1.1.0 - November 12, 2026
- **Record Now**: one click records the screen along with the readings, saved picture by picture so it survives the crash. Step through what was on screen in the final seconds.
- **Restarts that were asked for**: names the program that told Windows to restart - an updater, installer, remote tool or script.
- **Network share crashes**: shows the drivers on the crash stack, flags mup.sys, and names the outside drivers next to it.
- The System tab lists the file-system filter drivers (the same list as fltmc), with non-Windows ones marked.
- New reading: network share traffic.

## 1.0.0 - November 11, 2026
- First release: diagnosis of blue screens, sudden restarts and freezes; flight recorder; stress test; event timeline; automatic updates.
